Each page below covers one template: what it creates, and the fields you'll fill in to generate it. For the full `template.json` schema, generated file lists, and process commands behind each template, see the [Templates reference](/docs/engine-dev/tools/class-wizard/template-descriptor/templates/) in the Developer Guide.

| Template | What It Creates |
|---|---|
| [Basic Component](basic-component/) | A standard game component. |
| [Level Component](level-component/) | A component that attaches to the level entity. |
| [System Component](system-component/) | An engine-level system component that activates automatically. |
| [LyShine Component](lyshine-component/) | A UI component for the LyShine (UI 2.0) system. |
| [Data Asset](data-asset/) | A custom data asset type with its own asset handler. Also known as Generic Asset. |
| [Attimage](attimage/) | An attachment image asset for rendering features. |
